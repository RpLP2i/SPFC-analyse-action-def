5. Méthode de travail

  1. Choisir quelques actions représentatives, notamment celles qui conduisent à une entrée dans la surface, un centre, une frappe ou une occasion.
  2. Identifier le déclencheur : joueur non cadré, perte de balle, ballon arrêté, long ballon, deuxième ballon, etc.
  3. Séparer les faits visibles de l'hypothèse sur la cause.
  4. Enregistrer une sauvegarde JSON à la fin de l'analyse. La rouvrir pour continuer ou transférer le projet.
  5. Comparer les mêmes familles d'actions sur plusieurs matchs, même lorsque les groupes changent.
